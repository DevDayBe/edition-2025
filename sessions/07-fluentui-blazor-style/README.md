# Session 07 - FluentUI Blazor: Le combo gagnant pour des applis qui ont du style

  - Microsoft

## Session Info

Découvrez FluentUI Blazor et comment créer des applications .NET avec un design moderne et professionnel. Cette présentation éclair vous montrera comment utiliser ce combo gagnant pour améliorer l'expérience utilisateur de vos applications.
